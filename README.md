# TEOD CONTROL WEB PREMIUM V3

Versión premium de la página comercial para TEOD CONTROL.

## Qué incluye

- Landing page profesional de una sola página.
- Diseño cinematográfico industrial/tecnológico.
- Hero con panel visual interactivo.
- Servicios filtrables.
- Sistema comercial TEOD: captura, diagnóstico, propuesta, ejecución y entrega.
- Diagnóstico rápido por pasos que arma mensaje automático a WhatsApp.
- Formulario de cotización con mensaje directo a WhatsApp.
- Calculadora de costo de parada.
- Casos tipo listos para reemplazar con fotos reales.
- Modo claro/oscuro.
- PWA básica con `manifest.webmanifest` y `service-worker.js`.
- SEO básico, OpenGraph, sitemap y robots.
- Archivos para Netlify y Vercel.

## Probar localmente

```bash
cd teod_control_web_v3
python -m http.server 8080
```

Abrir:

```txt
http://localhost:8080
```

## Publicar rápido

### Netlify
1. Entra a Netlify.
2. Arrastra la carpeta `teod_control_web_v3`.
3. Conecta un dominio si ya tienes uno.

### Vercel
1. Sube la carpeta a GitHub.
2. Importa el repositorio en Vercel.
3. Deploy automático.

### GitHub Pages
1. Sube la carpeta a un repositorio.
2. Activa Pages desde Settings > Pages.
3. Usa la rama principal y la raíz del proyecto.

Para que la página se vea como empresa real y no como demo premium, reemplaza las ilustraciones de la sección de casos con fotos reales de:

- Tableros antes/después.
- Motores revisados.
- Placas de equipos.
- Botoneras, pilotos y protecciones.
- Trabajos terminados con buen encuadre.
