# Publicar la página en internet

## Opción más rápida: Netlify

1. Comprime o arrastra la carpeta `teod_control_web_v3` en Netlify.
2. Espera el deploy.
3. Netlify te dará una URL temporal.
4. Luego puedes conectar un dominio real.

## Opción profesional: GitHub + Vercel

1. Crea un repositorio en GitHub.
2. Sube todos los archivos de `teod_control_web_v3`.
3. Entra a Vercel e importa el repositorio.
4. Framework: Other / Static.
5. Output directory: dejar vacío o raíz.
6. Deploy.

## Dominio recomendado

Idealmente usar:

- `teodcontrol.com`
- `teodcontrol.ec`
- `teodcontrolindustrial.com`

## Antes de publicar oficialmente

- Reemplazar imágenes de casos por fotos reales.
- Agregar redes sociales si existen.
- Revisar ciudad/zona de cobertura.
- Confirmar número de WhatsApp.
- Agregar correo profesional si se crea uno.
